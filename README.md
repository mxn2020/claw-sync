# Claw Sync
> 🔄 Data synchronization hub for OpenClaw ecosystems.

[![CI](https://github.com/mxn2020/claw-sync/actions/workflows/ci.yml/badge.svg)](https://github.com/mxn2020/claw-sync/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## ✨ Features
- **🔗 Connections** — GitHub, Notion, Slack, S3 integrations
- **🔄 Sync Jobs** — Track sync executions with status and item counts
- **📊 Activity** — Full event timeline
- **⏰ Schedules** — Cron-based sync scheduling
- **🌗 Dark & Light Mode** — Ocean teal theme

## 🚀 Quick Start
```bash
git clone https://github.com/mxn2020/claw-sync.git
cd claw-sync && npm install && npm run dev
```
